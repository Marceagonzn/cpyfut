## ✨ Features

- ⚽ ASCII art of Paraguayan football clubs
- 🎨 Smooth color animations (256 colors)
- 🎠 Carousel mode
- 📦 Easy installation
- 🐧 Works on Linux terminals

---

## 🚀 Installation

```bash
git clone https://github.com/Marceagonzn/cpyfut.git
cd cpyfut
sudo ./install.sh
```

---

## 📖 Usage

```bash
cpyfut olimpia
```

```bash
cpyfut cerro
```

```bash
cpyfut olimpia --colors
```

```bash
cpyfut cerro --colors
```

```bash
cpyfut --carousel
```

```bash
cpyfut --carousel --colors
```

```bash
cpyfut --list
```
